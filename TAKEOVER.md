# TTT takeover (state 10.11.2026, build 590)

**What it is.** TTT, Talk to Type Advanced Keyboard: Marko's Android dictation keyboard (FlorisBoard/Dictate fork, package com.mantraproductions.tttlight). Repo markoboskoauroville/TTT (folder ~/Developer/TTT_MINI). Builds come only from GitHub Actions (releases build-NNN, Latest); install with `adb install -r`, never uninstall (it wipes keys and settings). Test phone: the Nothing; the Pixel 7 emulator is the default tester.

**State at build 590.**
- Keys: no manual key fields. Settings has one picker, "Import keys from file", plus "Re-test keys". It detects the provider by key shape, tests each key with a free authenticated call, keeps only the working ones encrypted in the Keystore. KeyRing numbers keys in file order (Groq-1, Groq-2, Gemini-1 ...) and rotates with a visible status ("Groq-1 out of free use -> Groq-2"); a daily-quota answer rests a key until 00:00 UTC, a rate limit a minute, a refused key an hour; every call starts at the lowest number not resting, so earlier keys return by themselves; cards show "N keys, active K" (10.11.2026). Diagnostics switch "Test: key 1 fails" (Feature row settings, off by default) makes key 1 answer a simulated 429. Feature-row width percent per button (MaKeyWidths.kt, pref maKeyWidths; H 40 / F1 20 / E 40 default for rows of 4 or fewer; steppers in Feature row settings); engine key labels stack in two lines when narrow, never clipped.
- Feature row widths (10.11.2026, build 596): every button has a width percent of its row (pref maKeyWidths, MaKeyWidths.kt); default for rows of 4 or fewer buttons H 40 / F1 20 / E 40; sum normalised, floor share 8% so labels are not cut; steppers for H, F1, E in Settings > Feature row. Installed on the Nothing A142 (versionCode 1596). **10.11.2026 (never switch engine).** The dictation path uses ONLY the engine Marko chose (EngineChain.dictate, one candidate). No answer / timeout / network error: wait 3 s and retry the same engine and key, up to 10 retries, status "Gemini - retry 2/10 - no internet"; then EngineGaveUp, the audio is kept and History offers Resend. Quota/401/403: KeyRing moves to the next key of the same provider; every key out: EngineGaveUp with a message, never another provider. A network error does not move the key ring. The AssemblyAI legacy path no longer falls to other engines nor to Parakeet. Open: AssemblyAI legacy path has no 3-second retry loop of its own.
