**What it is.** TTT, Talk to Type Advanced Keyboard: Marko's Android dictation keyboard (FlorisBoard/Dictate fork, package com.mantraproductions.tttlight). Repo markoboskoauroville/TTT (folder ~/Developer/TTT_MINI). Builds come only from GitHub Actions (releases build-NNN, Latest); install with `adb install -r`, never uninstall (it wipes keys and settings). **State at build 590.**
- Keys: no manual key fields. Settings has one picker, "Import keys from file", plus "Re-test keys". It detects the provider by key shape, tests each key with a free authenticated call, keeps only the working ones encrypted in the Keystore. Diagnostics switch "Test: key 1 fails" (Feature row settings, off by default) makes key 1 answer a simulated 429. Feature-row width percent per button (MaKeyWidths.kt, pref maKeyWidths; H 40 / F1 20 / E 40 default for rows of 4 or fewer; steppers in Feature row settings); engine key labels stack in two lines when narrow, never clipped.
